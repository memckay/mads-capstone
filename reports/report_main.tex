\section{Introduction}
- Introduce main issue - healthcare access/quality across USA: The Merit-based Incentive Payment System (MIPS) is used by Medicare/Medicaid to incentivize physician behaviors. Does MIPS actually improve ultimate patient outcomes?

- Discuss MIPS data (available to the general public): Using three separate government-provided datasets, each containing some features of interest

- Project scope: only examining county-level data (~3000 counties across the USA); using preventable hospitalizations as method to evaluate patient outcomes (the fewer the better)

\section{Methods}

\subsection{Data Sanitization}

- Adjust/sanitize data as necessary to account for missing data

\subsection{Exploratory Data Analysis (EDA)}
data profiling, duplicate checks, unique-value inspection, key cleaning, ZIP and county FIPS standardization, merge validation, weighted aggregation

\subsection{Supervised Learning}
- Linear regression w/ CIs

- Elastic Net (correlated measures + feature selection)

- tree ensemble (Random Forest / gradient boosting)

- Each fit with and without MIPS features, to test whether MIPS adds predictive value over demographic controls alone

- Grouped CV by state (neighboring counties are correlated) vs a demographics-only baseline

\subsection{Unsupervised Learning}
- PCA on MIPS measure matrix to reduce dimensionality and identify latent performance factors

- county clustering (K-Means + hierarchical) based on MIPS performance profiles to find natural groupings of counties

- silhouette scores/elbow method to determine optimal cluster count

\subsection{Supervised Learning}
A small, borderline association exists that is robust to demographic/specialty controls (but is functionally absorbed by a county’s own prior-year readmission rate)

- Effect is cross-sectional, not forward

- Adds essentially nothing beyond outcome history

- Three measures survive correction after the updated per-measure specification and coverage screen, all preventive care and all pointing the same way; the earlier mixed-sign result came from an all-measures model where the positive HIV screening coefficient disappears when fitted on its own.

- Much of the tree-model lift comes from reporting pattern

- Sparse exposure adds measurement noise, but self-selected reporting means the direction of bias is uncertain
